# Weather-App

A Node.js web application that shows the current weather forecast for any city using the Weatherstack API. Built with Express.js, Handlerbars (hbs) for templating, and CSS for styling.

⚡️ Features
1. Search for weather by city name
2. Real-time weather data
3. Error handling for invalid or missing input
4. Responsive UI with Handlebars templates

💻 Technology Used
1. Node.js
2. Express.js
3. Handlebars (hbs)
4. CSS
5. Weatherstack API
